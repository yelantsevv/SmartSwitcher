# SmartSwitcher for macOS

Легкая и производительная утилита для macOS в строке меню, которая мгновенно конвертирует выделенный текст между английской (QWERTY) и русской (ЙЦУКЕН) раскладками клавиатуры и обеспечивает мгновенное переключение языка.

---

## 📁 Структура проекта

- **`SmartSwitcher.app`** — готовое macOS приложение для папки «Программы» и автозагрузки.
- **`SmartSwitcher`** — скомпилированный консольный бинарный файл для быстрого запуска из Терминала или через Finder.
- **`main.swift`** — исходный код проекта на Swift.

---

## ✨ Возможности

- **Мгновенная конвертация (`Fn + Space`)**: выделите текст в любом приложении, нажмите `Fn + Space` — текст автоматически переводится на другой язык (например, `Ghbdtn` ➔ `Привет`), а раскладка клавиатуры переключается синхронно.  
- **Умная фильтрация**: автоматически игнорирует случайные нажатия на пустые строки без выделения текста.
- **Интеграция в строку меню**: работает в фоне как статус-агент, отображая текущую раскладку (`RU`/`EN`) или статус `OFF`, когда функция отключена.
- **Сохранение состояния**: запоминает состояние (включено/выключено) между запусками через `UserDefaults`.
- **Никаких лишних зависимостей**: написана на чистом Swift с использованием нативных API (Core Graphics, Carbon TIS, AppKit).

---

## 📋 Требования

- macOS 12.0 или новее.
- Разрешение на **Универсальный доступ (Accessibility)** в *Системных настройках* для перехвата глобального хоткея.

---

## 🚀 Варианты запуска

### Вариант 1. Использование приложения (`SmartSwitcher.app`)

1. Переместите `SmartSwitcher.app` в папку **Программы** (`/Applications`).
2. Запустите приложение.
3. При первом запуске перейдите в **Системные настройки ➔ Конфиденциальность и безопасность ➔ Универсальный доступ** и включите тумблер напротив **SmartSwitcher**.

#### 🔄 Добавление в автозагрузку (`SmartSwitcher.app`)
1. Откройте **Системные настройки** на Mac.
2. Перейдите в раздел **Основные ➔ Объекты входа**.
3. В блоке **«Открывать при входе»** нажмите кнопку **`+`**, выберите `SmartSwitcher.app` из папки «Программы» и нажмите **Открыть**.

---

### Вариант 2. Запуск бинарного файла через Терминал или Finder (`SmartSwitcher`)

Вы можете запустить скомпилированный бинарный файл `SmartSwitcher` двумя способами:

#### Через Терминал:
1. Откройте Терминал в папке с проектом.
2. Сделайте файл исполняемым (при необходимости):
   ```bash
   chmod +x SmartSwitcher
   ```
3. Запустите утилиту:
   ```bash
   ./SmartSwitcher
   ```
4. Для остановки нажмите: `Ctrl + C`.

#### Через Finder (двойным кликом):
1. Найдите файл `SmartSwitcher` в Finder.
2. Дважды кликните по нему — он автоматически откроется и запустится в новом окне Терминала.

> **Важно:** При запуске консольного бинарного файла напрямую или через Finder разрешение на Универсальный доступ (Accessibility) должно быть выдано приложению **Терминал** (`Terminal.app`), так как утилита исполняется внутри его процесса.

## 🛠 Сборка из исходного кода (`main.swift`)

Вы можете скомпилировать исходный код как в полноценный бандл приложения (`.app`), так и в одиночный консольный бинарный файл с помощью встроенного компилятора `swiftc`.

### 1. Сборка приложения (`SmartSwitcher.app`)

Компилирует исполняемый файл с оптимизацией и упаковывает его в структуру macOS-приложения:

```bash
# Компиляция бинарника с фреймворками
swiftc -O main.swift -o SmartSwitcher -framework AppKit -framework Carbon -framework CoreGraphics -framework ApplicationServices

# Создание структуры каталогов приложения
mkdir -p "SmartSwitcher.app/Contents/MacOS"

# Перемещение бинарного файла внутрь приложения
mv "SmartSwitcher" "SmartSwitcher.app/Contents/MacOS/SmartSwitcher"
```

После этого папку `SmartSwitcher.app` можно переместить в `/Applications`.

---

### 2. Сборка бинарного файла (`SmartSwitcher`)

Компилирует одиночный исполняемый файл для быстрого запуска через Терминал или Finder:

```bash
swiftc -O main.swift -o SmartSwitcher -framework AppKit -framework Carbon -framework CoreGraphics -framework ApplicationServices
```

Запуск скомпилированного бинарника:
```bash
./SmartSwitcher
```
